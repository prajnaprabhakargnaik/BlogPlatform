BlogPlatform – Blog Platform with Comments

Project Overview

BlogPlatform is a responsive blog website that allows users to create, manage, and explore blog posts. Users can register, log in, publish blogs, interact through comments, and search for content.

Features

- User Registration and Login
- Create, Edit, and Delete Blog Posts
- Add, Edit, and Delete Comments
- Search Blog Posts
- Like Blog Posts
- User Profile
- Responsive Design
- Local Storage for Data Persistence

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

Live Website : https://prajnablogplatform.netlify.app
